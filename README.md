# Предиктивная CSI/NPS обратная связь — кредитная карта

Frontend-прототип executive dashboard для демонстрации руководству банка: как предиктивная аналитика клиентского опыта помогает находить вероятных детракторов и промоутеров среди клиентов, которые не оставляли обратную связь.

## Что показывает прототип

- объём вероятных детракторов, потенциальных детракторов, нейтралов и промоутеров;
- продуктовые драйверы негативного и позитивного опыта;
- клиентские базы для исключения из продажных кампаний;
- клиентские базы для включения в care, retention, cross-sell и referral;
- ожидаемый эффект инициатив банка.

## Как запустить проект

```bash
npm install
npm run dev
```

Для production-сборки:

```bash
npm run build
```

Backend, базы данных, авторизация и внешние API не используются.

## Генерация синтетических данных

Файл генератора: `src/data/generateSyntheticData.ts`.

Генерируется минимум 5 000 синтетических клиентов по продукту «Кредитная карта». Для каждого клиента создаются:

- вероятность детракции и промоутерства;
- сегмент;
- продуктовые и поведенческие признаки;
- главный драйвер опыта;
- рекомендованное действие;
- флаги включения и исключения из инициатив.

Распределение сегментов приблизительно соответствует ТЗ:

- Вероятный детрактор — 13%;
- Потенциальный детрактор — 19%;
- Нейтрал — 40%;
- Потенциальный промоутер — 20%;
- Явный промоутер — 8%.

## Разделы сайта

1. Executive Summary с KPI-карточками.
2. Карта сегментов: donut chart, bar chart и таблица сегментов.
3. Драйверы клиентского опыта: графики детракции и промоутерства.
4. Продуктовые фичи и связанные клиентские базы.
5. Клиентский скоринг с рабочими фильтрами.
6. Симулятор инициатив для выбора целевой базы, исключений, эффекта, риска и канала.

## Какие данные используются

Используются только синтетические данные, созданные локально в коде. Реальные персональные данные, банковские системы и внешние источники не подключаются.

## Почему данные синтетические

Цель прототипа — показать управленческий результат и визуальную механику, а не обучать полноценную ML-модель. Синтетические данные позволяют безопасно продемонстрировать сценарий без рисков раскрытия персональных или банковских данных.
